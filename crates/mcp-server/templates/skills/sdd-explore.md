# SDD Explore

## Quick Start

Investigate the codebase to understand its structure and identify relevant components.

## Workflow

1. Read key files to understand the architecture
2. Identify the main entry points and modules
3. Analyze dependencies and relationships
4. Document findings in an exploration report

## Output Format

Return a structured exploration report with:
- **Architecture Overview**: High-level structure
- **Key Components**: Main modules and their responsibilities
- **Dependencies**: How components relate
- **Recommendations**: Suggestions for the proposed change
