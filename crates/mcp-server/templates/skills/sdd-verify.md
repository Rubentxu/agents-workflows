# SDD Verify

## Quick Start

Validate that implementation meets all specifications and acceptance criteria.

## Workflow

1. Review the implementation
2. Check against specifications
3. Verify acceptance scenarios pass
4. Run test suites
5. Document any deviations

## Output Format

Return verification results with:
- **Passed**: Criteria that met requirements
- **Failed**: Criteria that did not meet requirements
- **Deviations**: Differences from spec with rationale
