# SDD Design

## Quick Start

Create a technical design document that outlines the implementation approach.

## Workflow

1. Review specs and requirements
2. Analyze existing code structure
3. Design the solution architecture
4. Document key decisions and rationale
5. Identify dependencies and interfaces

## Output Format

Return a design document with:
- **Architecture**: High-level component design
- **Key Decisions**: Important choices with rationale
- **Interfaces**: Public APIs and contracts
- **Dependencies**: External requirements
