# SDD Archive

## Quick Start

Archive the completed change and update main documentation.

## Workflow

1. Verify all stages are complete
2. Sync delta specs to main specs
3. Document lessons learned
4. Archive all artifacts
5. Clean up temporary resources

## Output Format

Return archive summary with:
- **Completed**: All completed deliverables
- **Synced**: Updated main documentation
- **Artifacts**: Archived evidence
- **Lessons**: Key learnings from the change
