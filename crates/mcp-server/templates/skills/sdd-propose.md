# SDD Propose

## Quick Start

Create a structured proposal documenting the intent and approach for a change.

## Workflow

1. Review exploration findings
2. Define the problem statement
3. Outline scope and constraints
4. Document proposed approach
5. Identify risks and mitigations

## Output Format

Return a proposal with:
- **Problem**: What issue needs to be addressed
- **Scope**: What is included and excluded
- **Approach**: How the problem will be solved
- **Risks**: Potential challenges and mitigations
