# SDD Tasks

## Quick Start

Break down the design into concrete, actionable implementation tasks.

## Workflow

1. Review the design document
2. Identify implementation units
3. Break down into sequential tasks
4. Estimate dependencies between tasks
5. Prioritize tasks logically

## Output Format

Return a task list with:
- **Task ID**: Unique identifier
- **Description**: Clear action statement
- **Depends On**: Task dependencies
- **Acceptance Criteria**: What defines completion
