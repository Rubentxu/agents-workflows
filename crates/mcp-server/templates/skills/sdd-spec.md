# SDD Spec

## Quick Start

Write detailed specifications capturing requirements and acceptance scenarios.

## Workflow

1. Review the proposal for context
2. Define functional requirements
3. Write concrete acceptance scenarios
4. Specify edge cases and error handling
5. Document non-functional requirements if any

## Output Format

Return specifications with:
- **Requirements**: Clear, testable statements
- **Scenarios**: Given/When/Then format for each case
- **Edge Cases**: Boundary conditions to handle
